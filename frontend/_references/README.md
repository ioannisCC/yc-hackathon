# Design references

These files are **not imported** by the app. They document the visual vocabulary
the real components in `components/` are built from. Treat them as design DNA —
shape references, not building blocks. The user-facing components combine and
refine these patterns.

Mapping:

| Reference | Real component built from it |
|---|---|
| `liquid-glass-button.tsx` | `components/liquid-button.tsx`, `components/liquid-input.tsx` |
| `dynamic-island-toc.tsx`  | `components/dynamic-island.tsx` |
| `falling-pattern.tsx`     | `components/ambient-background.tsx` (FallingPattern layer) |
| `lamp.tsx`                | `components/ambient-background.tsx` (LampGlow layer) |
| `button.tsx`              | `components/liquid-button.tsx` |
